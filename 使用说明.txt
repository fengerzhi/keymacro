============================================================
  按键精灵 · 使用说明（先看这 3 行）
============================================================

  想马上用    →  双击  启动按键精灵.bat      （不用安装）
  想装到电脑  →  双击  安装按键精灵.bat      （装到开始菜单/桌面）
  想升级旧版  →  双击  一键覆盖更新.bat      （选中旧版文件夹即可）
  升级出问题  →  双击  诊断升级.bat          （生成一份升级环境报告）
  想发给别人  →  双击  生成安装包.bat        （产出 exe，对方无需 Python）


------------------------------------------------------------
  一、只想马上用（推荐先试这个）
------------------------------------------------------------

  1. 确保压缩包已经「全部解压缩」（不要在压缩包里直接双击！）
  2. 打开解压出来的文件夹，能看到 main.py 这个文件
  3. 双击  启动按键精灵.bat

  程序窗口会直接打开，不会装任何东西，也不会改注册表。
  关掉文件夹就相当于不用了。

  小提示：可以右键「启动按键精灵.bat」→ 发送到 → 桌面快捷方式，
         以后从桌面点就行。


------------------------------------------------------------
  二、正式安装（有开始菜单、桌面图标、可卸载）
------------------------------------------------------------

  1. 双击  安装按键精灵.bat
  2. 按提示回车确认
  3. 装完后会有：
       · 桌面图标「按键精灵」
       · 开始菜单里的「按键精灵」
       · 控制面板「程序和功能」里的卸载项

  安装位置：C:\Users\你的用户名\AppData\Local\Programs\按键精灵
  卸载方法：安装目录里的  卸载按键精灵.bat

  说明：这个安装器需要本机有 Python 3.9 以上（你已经装好了 3.14）。


------------------------------------------------------------
  三、打包成 exe（给没有装 Python 的电脑用）
------------------------------------------------------------

  1. 双击  生成安装包.bat（或 build\build_windows.bat，两者等价）
  2. 等几分钟（第一次会下载 PyInstaller）
  3. 完成后在 dist 文件夹里得到：
       dist\安装按键精灵.exe          ← 双击即装，无需 Python
       dist\按键精灵\按键精灵.exe     ← 绿色版，直接双击也能跑

  发给别人时，把 dist 里的「安装按键精灵.exe」发过去就行。


------------------------------------------------------------
  四、升级新版本（不需要 GitHub）
------------------------------------------------------------

  程序里点工具栏的  🔄 升级  按钮：

  方式一 · 升级文件夹（推荐，设置一次就行）
    · 选一个文件夹，比如 D:\按键精灵更新（也可以是 U 盘、
      局域网共享 \\电脑名\共享、坚果云/OneDrive 的同步目录）
    · 以后把新版本的 zip 丢进这个文件夹
    · 再点「🔄 升级」就会自动完成：下载/取包 → 关程序 → 替换 → 重启

  方式二 · 直接选包
    拿到新版本 zip 时，点升级窗口里的「选择 zip 文件并升级」

  升级窗口里还有「生成升级包到这个文件夹」按钮，
  可以把当前版本打成一个 zip，复制到别的电脑实现同步升级。

  ▲ 放了新 zip 却提示「已经是最新版本」怎么办？
    · 新版程序（v1.4.2 起）会自动从 zip 里读出版本号，不用管。
    · 旧版程序（v1.4.1 及以前）读不出整包版本号，会误报「已是最新」。
      办法：把交付包里的 version.json 一起复制到升级文件夹
            （里面写着版本号和包名），再点升级即可识别。
    · 或者干脆不用升级功能：解压新包，双击「安装按键精灵.bat」覆盖安装一次，
      之后就都是新版了。

  ▲ 升级后多出一个乱码名字的文件夹（如 ????-Windows?? (1)）？
    这是 v1.4.3 及以前版本的 bug：升级脚本把中文路径解码错了，
    文件被复制到一个乱码目录里，新版本其实没装上。
    最省事的处理办法（推荐）：
      1. 删掉那个乱码文件夹（里面只是升级包的副本，删了不影响使用）
      2. 解压新版压缩包
      3. 双击新包里的「一键覆盖更新.bat」
      4. 在弹出的窗口里选中**旧版程序所在的文件夹**（里面要有 main.py），确定
      5. 完成后勾选「启动」，即完成升级
    也可以手动做：把新包里的文件全选复制，粘贴到旧版文件夹，选「替换」。

  ▲ 点了升级，程序关掉又打开，版本号却没变？（v1.7.0 起能查出原因）
    升级是「程序退出后由另一个程序接着替换文件」，以前的版本一旦替换失败
    就什么都不说，看起来跟没点一样。v1.7.0 起：
      1. 进度、替换、核对全程写日志：
         C:\Users\你的用户名\.macro-sprite\logs\upgrade_*.log
         （升级窗口右下角有「升级日志」按钮，点一下直接打开）
      2. 替换完会逐个核对关键文件，没换成功会弹窗写明是哪几个文件；
      3. 下次启动会检查「上次升级成没成」，没成会直接告诉你。
    还是查不出来就双击  「诊断升级.bat」，
    它会把版本、安装目录、升级文件夹内容、日志一次性收集成一份报告，
    把报告发过来即可定位。

  ▲ 常见原因（按出现频率）
    · 程序没真正退出（有未保存脚本时点了「取消」）：v1.7.0 起升级会
      自动备份当前脚本并强制退出，不再卡住。
    · 装的是 exe 版，却拿源码 zip 去升级（或反过来）：v1.7.0 起会提前提示。
    · 升级文件夹里 version.json 写的包名和实际文件不一致（整包解压过）：
      v1.7.0 起会自动改用文件夹里实际的 zip。
    · 程序装在 C:\Program Files 之类需要管理员权限的目录：换个目录重装一次。
    · 杀毒软件拦了替换：临时关掉杀毒再升级，或用「一键覆盖更新.bat」。

  GitHub 只是「高级」里的可选项，完全不用也不影响升级。


------------------------------------------------------------
  五、删错了能退回（撤销 / 搜索 / 折叠）
------------------------------------------------------------

  · 撤销 / 重做
      Ctrl+Z 撤销，Ctrl+Y 重做，最多能退 60 步。
      删除、改时间、改间隔、统一间隔、加注释、插指令、清空，
      全都可以撤销。按钮在事件列表左上方「↶ 撤销 / ↷ 重做」。

  · 搜索某一步
      Ctrl+F 或直接点事件列表上方的搜索框，输入关键字（如「单击」「等待」），
      列表只显示匹配的步骤；回车跳到下一个，Esc 或 ✕ 清除。

  · 折叠循环
      双击最左边的序号列，或点「⊟ 折叠」，
      整个循环块收成一行「已折叠 N 步」，长脚本一眼看清结构。
      右键菜单里也有「折叠/展开循环」。

  · 回放倒计时
      点「▶ 回放」后先倒数 3 秒再开始，给你时间切到目标窗口。
      秒数在右侧「脚本设置 → 回放倒计时」改，填 0 关闭。
      倒计时期间再点一次「回放」或按 F10 即可取消。

  · 开始录制时不会悄悄清空
      已有事件时，会问你「清空重录 / 追加到末尾」。
      选追加会把新录的接在最后，并在 ~/.macro-sprite/backup/ 留一份备份。
      勾「记住我的选择」，以后就不再问。

  · 程序崩了怎么办
      不会再无声消失：会在 logs 目录写一份 crash_*.txt，
      并弹窗告诉你文件位置，把这个文件发我就能定位问题。

  · 有改动没保存就关窗口
      会先问你「要保存吗」。标题栏出现「● 未保存」就说明还没存。


------------------------------------------------------------
  六、把脚本发给别人 / 换台电脑用
------------------------------------------------------------

  · 保存成「单文件脚本包」（.ajjl）—— 推荐
      菜单「保存」默认就是这个格式，一个 .ajjl 文件里装好了：
        脚本本体 + 用到的图片 + 数据表
      发给同事、拷到别的电脑，图片不会丢，找图步骤照常能用。

      脚本库里的脚本：选中 → 点「导出」，同样是 .ajjl。

  · 打开别人给的脚本
      菜单「打开」直接选 .ajjl 就行，图片会自动释放到
      ~/.macro-sprite/packages/ 下面，不用你手动摆位置。
      旧的纯 .json 脚本也照样能打开。

  · 找图步骤跑不通会提前告诉你
      回放前如果发现「图片文件找不到」，
      会先弹窗说明是第几步、缺什么，让你决定要不要继续，
      不会像以前那样默默跳过、看着像点了其实没点。

      找图能力已内置，不用再装任何组件：指令库点「找图点击」，
      选一张事先截好的图片即可（相似度默认 90，图标类建议 85）。

      适合点任务栏图标、菜单项这类位置会变的地方：
      程序先找到图片再点它的中心，不依赖固定坐标。
      截图时只截目标本身、别带大片背景——纯色图没有特征，找不准。

      · 图片对比度太低（大片纯色、淡淡渐变）会在选图时就被拒绝，
        这类图在屏幕上到处都「像」，回放必然点错
      · 相似度越高越严格：老是点错就把 90 提到 95，该点没点上就降到 85
      · 屏幕上有多处几乎一样的图时，程序判定不可信、宁可不点，
        避免点到不相干的位置

  · 回放出错会自动跳行
      回放中途出错，会跳到出错那一行、选中并标成浅红底，
      弹窗里也写着「出错位置：第 N 步 xxx」，不用再去翻日志找。


------------------------------------------------------------
  七、出问题了怎么办
------------------------------------------------------------

  · 双击 bat 一闪而过
      不要双击，改成：在文件夹地址栏输入 cmd 回车，
      然后输入  安装按键精灵.bat  回车，报错会留在屏幕上。

  · 双击没反应 / 提示找不到 Python
      打开 cmd 输入  python --version  看是否有版本号。
      没有就去 https://www.python.org/downloads/ 装，
      安装时务必勾选 "Add python.exe to PATH"。

  · 打包时窗口闪一下就没了
      说明脚本遇到语法错误直接退出了（旧版在带括号的路径下会这样）。
      新版已修好。如果还有问题，请改用命令行，报错会留在屏幕上：
        在文件夹地址栏输入 cmd 回车，然后输入
        python build\build.py
      打包失败时会自动生成「打包日志.txt」，把它发我就行。

  · 想知道环境哪里有问题
      双击 build\自检.bat，它会把 Python、依赖、文件是否齐全
      全部打印出来并停住。

  · 提示「找不到 main.py」
      说明压缩包没解压完，或只解压了一部分。
      右键压缩包 → 全部解压缩 → 打开新文件夹 → 再运行。


------------------------------------------------------------
  文件都是干什么的
------------------------------------------------------------

  启动按键精灵.bat    免安装，直接运行（最省事）
  安装按键精灵.bat    正式安装到本机
  生成安装包.bat      打包成 exe + 安装程序
  卸载按键精灵.bat    卸载（安装后副本在安装目录里）
  install.py          安装逻辑本体
  uninstall.py        卸载逻辑本体
  main.py             程序入口
  core\  ui\  assets\ 程序代码与图标
  build\              打包与自检脚本
  打包说明-Windows.md 更详细的打包文档
