# 按键精灵 · 桌面版

系统级鼠标键盘录制 / 回放工具。基于 Python + pynput + tkinter。
注入的是**真实系统输入**（isTrusted=true），可操作任意软件。

## 核心功能

### 鼠标
- **左键 / 右键 / 中键** 点击（右键可调出上下文菜单）
- **双击** 自动识别（400ms / 6px 阈值内两次左键）
- **拖拽** 自动识别（按下移动 >6px 释放，回放时模拟真实轨迹分 12 步移动）
- 滚轮滚动

### 键盘
- 输入任意文本（录制时自动聚合，含中文）
- **组合键**：Ctrl+C 等自动识别；按下顺序 / 释放逆序精确还原；支持三键及以上（Ctrl+Shift+S）
- **语义化编辑指令**（录制自动识别 + 指令库手动插入）：

| 指令 | 按键 | | 指令 | 按键 |
|---|---|---|---|---|
| 全选 | Ctrl+A | | 撤销 | Ctrl+Z |
| 复制 | Ctrl+C | | 重做 | Ctrl+Y |
| 剪切 | Ctrl+X | | 回车 | Enter |
| 粘贴 | Ctrl+V | | 取消 | Esc |
| 删除 | Delete | | 切换焦点 | Tab |

### 借鉴成熟按键精灵的扩充能力
- **指令库面板**：点击即插入「左键/右键/双击/拖拽/全选/复制/剪切/粘贴/删除/输入文本/组合键/等待/循环/找图/注释」
- **屏幕取点工具**：全屏半透明覆盖 + 十字线跟随 + 实时坐标气泡，单击取点、Esc 取消；
  连取两点自动生成拖拽指令，坐标为屏幕绝对坐标（与回放一致）
- **全局热键**（程序最小化/后台依然生效，支持自定义绑定）：
  - `F9` 停止录制　`F10` 中断回放　**`F11` 一键开始/停止脚本**（无需切回工具窗口）
- **单步调试**：`⏭ 单步` 执行选中行并自动跳到下一行；`⤓ 执行到此` 从头跑到选中行，便于逐段验证
- **循环块**：`loop_start × N` … `loop_end`，支持嵌套；整体回放另支持循环次数
- **找图点击**：直接在屏幕上**框选目标**，松手即自动截图存模板并添加指令（不弹任何窗口，
  模板存于 `~/.macro-sprite/images/`）；回放时内置模板匹配定位并点击中心
  （numpy 实现，随包提供，无需另装依赖）
- **条件执行**：`if_image` 屏幕出现某图才继续
- **随机延时抖动**（防行为检测）与**失败重试**次数
- **脚本库侧栏**：脚本集中存放于 `~/.macro-sprite/scripts/`，支持搜索过滤、按名称/创建时间/最近使用排序；
  打开 / 保存 / 另存 / 重命名 / 复制 / 删除（移入回收目录可恢复）/ 导入 / 导出 / 一键打开目录；
  重名自动加序号，索引文件损坏时自动从目录重建，写入采用原子替换防损坏
- **执行日志面板**：每次回放实时显示逐步日志（✓ 成功 / ! 警告 / ✗ 失败三色），
  同时落盘为 JSONL（`~/.macro-sprite/logs/`，逐行追加，崩溃不丢数据）；
  支持「历史」查看器回读任意一次执行的完整记录、「打开目录」「清理 30 天前旧日志」
- **失败自动截图**：回放出错 / 找图未命中时自动截屏存证（`logs/screenshots/`），
  日志中附带截图文件名；截图链路 PIL → scrot → import → xwd 四级降级
- **事件编辑**：双击修改内容/坐标/组合键，右键菜单，启用/禁用单步，调整时间，插注释
- **间隔列**：列表在「时间」右侧单列显示每步与上一步的间隔（秒）；
  双击「间隔」单元格或点「改间隔」即可修改，改完该行之后的步骤时间整体平移、
  各自的间隔保持不变；「统一间隔…」可把选中行的间隔一键设为同一值
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y，最多 60 步；删除、改时间、改间隔、统一间隔、
  加注释、插指令、清空全部可撤销（快照式，录制中不占栈）
- **列表搜索**：Ctrl+F 或顶部搜索框，按动作文字/输入内容/注释过滤，回车跳下一个，Esc 清除
- **循环折叠**：双击序号列或「⊟ 折叠」，循环块收成一行「已折叠 N 步」，长脚本不再难翻
- **回放倒计时**：默认 3 秒（0-10 可调，填 0 关闭），期间再点回放或按 F10 取消
- **录制不丢数据**：开始录制前询问「清空重录 / 追加到末尾」，追加自动接在末尾并备份到
  `~/.macro-sprite/backup/`
- **崩溃留痕**：`sys.excepthook` + `threading.excepthook` + `report_callback_exception`
  三级兜底，异常写入 `logs/crash_*.txt` 并弹窗告知路径，不再无声消失
- **未保存保护**：关闭窗口、打开其他脚本、从脚本库切换前都会提示保存，标题栏显示「● 未保存」
- **录制实时预览**：边录边看事件列表增长
- **单文件脚本包（.ajjl）**：保存默认打包，脚本 + 图片 + 数据表装进一个文件，
  发到别的电脑不会「找不到图」。解包时附件释放到 `~/.macro-sprite/packages/<包名>-<摘要>/`，
  同一包重复打开复用同一目录；纯 JSON 脚本仍可正常读写
- **回放出错自动跳行**：定位到出错那一行并标浅红底，弹窗给出「出错位置：第 N 步」
- **找图前置检查**：缺图片或缺找图组件时提前说明是第几步、缺什么，
  不再静默跳过；回放正常结束但有未命中步骤时，状态栏给出提示
- **脚本导入导出**：`.ajjl` 单文件包 / 纯 JSON 两种，跨机器分发

## 坐标不准？两步排查

1. **看状态栏 DPI 提示**：显示 `DPI OK：Per-Monitor V2` 即已开启高 DPI 感知（绝大多数偏移由此根治）
2. **仍不准** → 工具栏「🎯 校准坐标」按提示点两下，程序自动算缩放与偏移

配合仓库根目录的 **测试页.html**（浏览器打开）可量化验证精度：
录制点击 9 个红点后回放，页面会显示每次点击的偏差像素与命中率，
能直接区分「整体偏移」（校准可救）与「比例缩放」（DPI 问题）。

## 运行

```bash
pip install -r requirements.txt        # 基础：pynput / pillow / numpy
python main.py
```

## 打包 exe

| 平台 | 命令 | 产物 |
|---|---|---|
| Windows | 双击 `build\build_windows.bat` | `dist\按键精灵.exe` |
| macOS | `python3 build/build.py` | `dist/按键精灵.app` |
| Linux | `python3 build/build.py` | `dist/按键精灵/` |

## 目录结构

```
macro-desktop/
├── main.py               # 入口（依赖检查 + 友好报错）
├── build/
│   ├── build.py          # 一键打包（自动选择可用解释器）
│   └── build_windows.bat # Windows 双击打包
├── core/
│   ├── script_model.py   # 事件模型 / 语义指令表 / JSON 序列化 / 结构校验
│   ├── recorder.py       # 录制器：组合键识别、语义指令、双击/拖拽、去重
│   ├── player.py         # 回放引擎：重试/抖动/循环/找图，逐步写日志
│   ├── hotkey.py         # 全局热键管理（150ms 去重、冲突检测）
│   ├── window.py         # 跨平台窗口聚焦
│   ├── library.py        # 脚本库：索引/搜索/重命名/回收站/原子写入
│   ├── logger.py         # 执行日志 JSONL + 失败截图（四级降级）
│   └── ...
├── ui/
│   ├── app.py            # 主界面（脚本库 + 事件时间轴 + 日志面板 + 指令库 + 设置 + 调试）
│   └── picker.py         # 屏幕取点工具（十字线/多点/实时坐标）
└── test_ui_library.py    # UI 集成测试（30 项）
```

## 平台注意

- **Windows**：开箱即用
- **macOS**：系统设置 → 隐私与安全性 → 辅助功能 中授权
- **Linux**：X11 会话最佳（建议 `sudo apt install xdotool`）；Wayland 受限
